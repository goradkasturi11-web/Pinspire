PINSpire - Pinterest-style prototype

HOW TO RUN
1. Extract this ZIP file.
2. Open the pinterest_clone folder.
3. Double-click index.html, or open it in Chrome/Edge.

SAVED DATA
Pins, boards, saved-board assignments, and followed creators are saved in this browser using localStorage. They should remain after refresh or closing the browser on the same computer and browser.

IMPORTANT
- Data is stored only in this browser on this computer; it is not synced to other devices or users.
- Do not clear this site's browser data if you want to keep your saved content.
- Uploaded images are stored in browser localStorage as image data. Very large images may exceed the browser's storage limit; use smaller images if saving fails.
- This is a frontend demonstration prototype, not a cloud-backed multi-user service.
